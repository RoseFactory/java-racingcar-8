# java-racingcar-precourse

## 구현

### 설계 

전체 프로그램을 `Race` 클래스와 `Car` 클래스로 나누어 설계하였다.

1. `Race` 클래스
   - 사용자가 입력한 횟수와 현재 진행 횟수를 관리한다.
   - `Car`의 목록을 `List`로 관리한다.
   - 모든 진행을 담당한다.
   
2. `Car` 클래스
   - 이름과 위치를 관리한다.
   - 앞으로 진행할 수 있고, 이름을 받아올 수 있다.
   
### 구현 목록
- [x] 전체 클래스의 필드와 메소드 시그니처를 작성하고, `App`에서 입력을 받아 의존 관계를 설정한다.
- [x] `Car`가 진행하는 메소드를 작성한다.
- [x] `Race`의 전체 흐름을 담당하는 메소드를 작성한다.
- [x] `Race`가 한 번 진행할 때, 랜덤하게 자동차의 위치를 갱신하는 메소드를 작성한다.
- [ ] `Race`의 현재 상태를 출력하는 메소드를 작성한다.
- [ ] `Race`가 끝날 때, 우승자를 구하는 메소드를 작성한다.
